# 🐾 多人聯盟點名系統（小貓AB攜）

專為多人聯盟設計的網頁點名與公會成員管理系統，可直接部署至 **GitHub Pages** 供全體會長與成員共同使用。

## ✨ 核心功能

1. **會長名稱登入與權限控管 + 修改紀錄留存**
   - 登入輸入框內建提示與快速選擇 **6 位授權會長**：`大牛`、`LP33`、`小烏`、`蘆薈`、`RYUU`、`森森`。
   - 僅此 6 位會長登入時擁有新增/修改/刪除公會、匯入名單與勾選簽到的權限；其他名稱登入則為「唯讀模式」。
   - **完整修改紀錄（Audit Log）**：任何新增/刪除公會、增減成員、勾選/取消簽到，都會自動記錄「操作時間、會長名稱、動作類型與詳細內容」，並支援篩選與匯出 Excel。

2. **Excel 名單上傳 & 圖片辨識玩家名稱 (OCR) & 匯出名單**
   - **Excel / CSV 匯入**：支援 `.xlsx`, `.xls`, `.csv`，可匯入單一公會或依表格內「公會名稱 + 玩家名稱」自動分配至各公會（內附範例範本下載）。
   - **圖片 OCR 辨識**：內建免費離線 `Tesseract.js`（繁體中文 + 英文），支援拖曳圖片或直接按 `Ctrl + V` 貼上遊戲名單截圖，並提供「遊戲黑底白字增強」預處理與辨識後文字微調預覽區。
   - **Excel 匯出**：可隨時匯出單一公會名單、聯盟全體成員總表，或當日點名大表報表（`.xlsx`）。

3. **公會自由新增與刪除（雙重防呆機制）**
   - 可隨時新增公會分頁或修改公會名稱。
   - 刪除公會按鈕具備**雙重防呆機制**：需手動輸入該公會完整名稱並勾選確認方塊後才能解鎖刪除按鈕，避免誤刪。

4. **當日點名大表 & 各公會分頁連動**
   - 一鍵「新增今日點名大表」自動帶入當天日期（`YYYY-MM-DD`），亦支援自訂日期場次。
   - 在各公會獨立分頁勾選出席成員後，**即時同步匯總至「點名大表總覽」**，顯示當日簽到總人數、出席率、各公會統計小卡，以及包含「玩家名稱、公會名稱、簽到狀態、簽到時間、勾選會長」的完整細項。

---

## 🚀 如何上傳到 GitHub Pages 並讓所有人同步資料？

1. 將本資料夾內的 `index.html`、`style.css`、`app.js`、`README.md` 上傳至您的 GitHub Repository。
2. 進入 GitHub Repository 的 **Settings** ➔ **Pages**，在 Build and deployment 選擇 `Deploy from a branch`（選擇 `main` 分支），儲存後即可取得公開網址。
3. **開啟多人即時同步**：
   - 點擊網頁右上角的 **「☁️ 多人同步設定」**，依照視窗內的 1 分鐘教學貼上免費的 Firebase Realtime Database 網址。
   - 點擊 **「🔗 複製給其他會長的專屬同步網址」** 發給另外 5 位會長，所有人點開該網址即可即時同步所有公會、名單、簽到狀態與修改紀錄！
